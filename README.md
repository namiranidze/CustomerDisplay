# მომხმარებლის ახალი ეკრანი

როგორ მუშაობს მყიდველის ეკრანის ახალი პროგრამა, საიდან მოაქვს ვიდეოები, როდის შლის ძველს და რა სჭირდება სალაროს.

**სქემა**

- **ეკრანის მართვა:** 1C (ფარმაცევტის ინტერფეისი)  → `CustomerDisplay.exe` → მეორე მონიტორი
- **ვიდეო:** საერთო საქაღალდე → ერთხელ კოპირება → ლოკალური ასლი სალაროს დისკზე → ეკრანმზოგი

## რა არის

პროგრამა: `C:\CustomerDisplay\CustomerDisplay.exe`. ცალკე Windows-სერვისი ან სერვერი არ სჭირდება. როცა ფარმაცევტი ინტერფეისს ხსნის, 1C პროგრამას თვითონ უშვებს, დახურვისას კი თვითონ ხურავს.

> **ყურადღება:** 1C ეკრანს მხოლოდ მაშინ უშვებს, როცა „მომხმარებლის ეკრანის გამოყენება“ ჩართულია და „მომხმარებლის ეკრანის ფაილის მისამართი“ შევსებულია. ვიდეოს მისამართი ცარიელი თუ არის, ეკრანი მაინც იმუშავებს, ოღონდ ახალ ვიდეოებს არ ჩამოტვირთავს.

## როგორ ელაპარაკება 1C

პროგრამას შიგნით პატარა ლოკალური „მიმღები“ აქვს. ის მხოლოდ იმავე კომპიუტერიდანაა ხელმისაწვდომი, ქსელიდან არა.

- ყოველ ცვლილებაზე (კალათა, ფასდაკლება, გადახდა) 1C მას მოკლე შეტყობინებას უგზავნის: „ეს აჩვენე“. ეკრანს პროგრამა თვითონ ხატავს.
- ძველი სქემისგან განსხვავებით, 1C ყოველ ჯერზე მთელ HTML ფაილს აღარ წერს.
- ერთ სერვერზე რამდენიმე სალარო თუ მუშაობს (ტერმინალური სერვერი), თითოეულს თავისი არხი აქვს და ერთმანეთში არ ერევა.

## ვიდეოები ლოკალურად იტვირთება

- **წყარო:** სალაროს ბარათის ველი „მომხმარებლის ეკრანის ვიდეოს მისამართი“. იქ წერია ან საერთო საქაღალდე (მაგ. `\\server\video`), ან `;`-ით გამოყოფილი http ბმულები.
- **ჩამოტვირთვა:** თითო ფაილს პროგრამა ერთხელ აკოპირებს კომპიუტერზე და იქიდან უკრავს. ქსელიდან სტრიმინგი არ ხდება, ტრაფიკი მხოლოდ პირველ ჩამოტვირთვაზე და ფაილის შეცვლისას იხარჯება.
- **შემოწმება:** ყოველ 15 წუთში საქაღალდეს ამოწმებს. ახალ ფაილს მაშინ იღებს, როცა ის საქაღალდეში 1 წუთი უცვლელად დევს, რომ ნახევრად ჩაწერილი არ წამოიღოს.
- **თანმიმდევრობა:** ფაილის სახელით, წრიულად. ფორმატია mp4 (ასევე m4v, webm, ogv).
- **მარკეტინგს** მხოლოდ საქაღალდეში ფაილების შეცვლა სჭირდება. სალაროებზე 15–16 წუთში აისახება, 1C-ში არაფერი იცვლება.

## ძველ ვიდეოებს თვითონ შლის, ოღონდ არა უცებ

| დრო | რა ხდება |
|---|---|
| 0 წთ | საქაღალდეში ვიდეო შეიცვალა ან წაიშალა. |
| ≤ 15 წთ | შემდეგ შემოწმებაზე პროგრამა ახალ სიას აწყობს და ახალ ვიდეოს ჩამოტვირთავს. ძველ ასლს ჯერ ტოვებს, რომ ეკრანზე მიმდინარე ვიდეო შუაში არ გაწყდეს. |
| ≤ 30 წთ | მომდევნო შემოწმებაზე ლოკალურად მხოლოდ ის რჩება, რაც ახლა საქაღალდეშია. დანარჩენი იშლება, ნახევრად ჩამოტვირთული ფაილების ჩათვლით. |

- **ქსელი ან საქაღალდე თუ მიუწვდომელია,** არაფერს შლის და ძველ ვიდეოებს აგრძელებს. ცარიელ ეკრანს არ დატოვებს.
- **იმავე სახელით შეცვლილ ფაილს** ახლად აღიქვამს, რადგან ზომასა და შეცვლის თარიღს ადარებს. ძველი ვერსია იგივე წესით წაიშლება.
- **დაკავებული ფაილი:** თუ წაშლის მომენტში ფაილი დაკავებულია, მომდევნო შემოწმებაზე ისევ ცდის.
- **„მომხმარებლის ეკრანის ვიდეოს მისამართი“ თუ შეიცვალა** სალაროს ბარათში, ძველი საქაღალდის ვიდეოებიც იგივე წესით წაიშლება.

## სურათები და ლოგოები

მოდის სალაროს ბარათის ველიდან „მომხმარებლის ეკრანის ფაილის მისამართი“. ისინიც პირველ საჭიროებაზე ერთხელ ჩამოიტვირთება და ლოკალურად ინახება.

> **ყურადღება:** თუ სურათს იმავე სახელით შეცვლით, პროგრამა თვითონ ვერ განაახლებს: ახალი სახელით უნდა დაიდოს.

## ეკრანები

- კალათა
- ფასდაკლებები
- ბონუსები
- საჩუქრები

- ეკრანმზოგი (ვიდეოები)

## ფანჯარა

- ავტომატურად მეორე მონიტორზე იხსნება.
- მეორე მონიტორი თუ არ არის, იმალება და მონიტორის მიერთებისას თვითონ გამოჩნდება.
- მყიდველი ეკრანს თუ შეეხება, ფარმაცევტის 1C-ს ფოკუსი არ ეკარგება.

## თუ პროგრამა გაითიშა

- 1C კავშირს თუ ვერ დაამყარებს, პროგრამას თვითონ ხელახლა გაუშვებს (მაქსიმუმ 30 წამში ერთხელ) და ბოლო მდგომარეობას აჩვენებს.
- ერთდროულად პროგრამის მხოლოდ ერთი ასლი მუშაობს.

## რა სჭირდება სალაროს

- საქაღალდე `C:\CustomerDisplay` (პროგრამა და `config.json`). .NET ცალკე დასაყენებელი არ არის, პროგრამაშივეა.
- Microsoft Edge WebView2 Runtime. Windows 10/11-ზე როგორც წესი უკვე დაყენებულია, ძველი HtmlViewerCore-იც მასზე მუშაობდა.
- ვიდეოების საქაღალდის წაკითხვის უფლება მოლარის Windows მომხმარებელს.
- დისკზე ადგილი ვიდეოებისთვის.

> **ტერმინალური სერვერი:** ვიდეოები თითო Windows მომხმარებელზე ცალკე ინახება: 10 მოლარე ნიშნავს 10 ასლს. ასლები მხოლოდ მაშინ იშლება, როცა იმ მომხმარებელთან პროგრამა გაეშვება. იმ მოლარის ასლები, რომელიც აღარ მუშაობს, დისკზე დარჩება, სანამ ხელით არ წაიშლება: `%LOCALAPPDATA%\CustomerDisplay\videos`

## პარამეტრები და ჟურნალი

პარამეტრები ინახება `C:\CustomerDisplay\config.json`-ში:

| პარამეტრი | რას ნიშნავს | ნაგულისხმევი |
|---|---|---|
| `screen` | რომელ მონიტორზე გამოჩნდეს; 0 ნიშნავს პირველ დამატებით მონიტორს | 0 |
| `videoCheckMinutes` | რამდენ წუთში ერთხელ შეამოწმოს ვიდეოები | 15 |
| `thanksSeconds` | რამდენ წამს ჩანდეს „მადლობა“ | 5 |
| `restartPause` | რამდენ წამში ერთხელ შეიძლება 1C-მ პროგრამა ხელახლა გაუშვას | 30 |

ჟურნალი: `%LOCALAPPDATA%\CustomerDisplay\log.txt`. აქ ჩანს, რა ჩამოიტვირთა და რა შეცდომა მოხდა.
